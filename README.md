# AI Sky Observer

> AI-powered environmental sensors for Home Assistant using LLM Vision.

## Overview

AI Sky Observer transforms one or more outdoor security cameras into intelligent environmental sensors.

Instead of relying solely on weather forecasts, AI Sky Observer observes the sky above your own property using AI vision.

Current capabilities include:

- ☁️ AI Cloud Cover
- ☀️ Sun Visibility
- 📷 Multi-camera support
- 🧠 Google Gemini support
- 🌅 Sun-aware weighting
- 🏡 Designed for Home Assistant

## Design Philosophy

AI observes.

Home Assistant decides.

The AI never controls devices directly.
It simply reports observations that Home Assistant can use in automations.
