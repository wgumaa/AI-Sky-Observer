# 🛣️ AI Sky Observer Roadmap

This roadmap outlines the planned evolution of **AI Sky Observer**.

The goal is to transform AI Sky Observer from a cloud observation tool into a comprehensive AI-powered environmental observation platform for Home Assistant.

As with any open-source project, priorities may change based on community feedback and new ideas.

---

# Milestone 1 — Cloud Observer (v0.1.x)

Establish the core platform for AI-powered sky observation.

### Features

- ✅ AI Cloud Cover Estimation
- ✅ Direct Sun Visibility Detection
- ✅ Analysis Confidence Scoring
- ✅ Multi-camera Support
- ✅ Aggregate Cloud Cover Sensor
- ✅ Sky Condition Sensor
- ✅ Optional Home Assistant Dashboard

---

# Milestone 2 — Sky Observer

Expand analysis beyond cloud cover to better understand overall sky conditions.

### Planned Features

- ☀️ Sky Brightness Estimation
- 🌤 Enhanced Sky Condition Classification
- 🌥 Cloud Density Estimation
- 🌅 Sunrise and Sunset Visibility
- 🌈 Atmospheric Visibility Assessment

---

# Milestone 3 — Weather Observer

Detect additional weather conditions directly from outdoor cameras.

### Planned Features

- 🌧 Rain Detection
- ❄️ Snow Detection
- 🌫 Fog Detection
- 🔥 Smoke Detection
- 🌩 Storm Recognition
- 💨 Haze Detection

---

# Milestone 4 — Camera Health

Monitor camera image quality to improve AI reliability.

### Planned Features

- 🕸 Spider Web Detection
- 🧼 Dirty Lens Detection
- 💧 Condensation Detection
- 🌿 Vegetation Obstruction Detection
- 🚧 Camera Obstruction Detection
- 📷 Camera Health Status

---

# Milestone 5 — Intelligence Platform

Expand AI Sky Observer into a flexible observation platform.

### Planned Features

- 📈 Historical Sky Statistics
- 📊 Observation Trends
- 🧠 Smarter AI Confidence Models
- 🛰 Multiple Observation Zones
- 📷 Support for Additional Cameras
- 🔌 Blueprint and Integration Support

---

# Version 1.0

Version 1.0 will represent the first stable public release of AI Sky Observer, featuring:

- Reliable AI-powered sky observation
- Camera health monitoring
- Expanded weather detection
- Comprehensive documentation
- Stable Home Assistant package
- Community feedback incorporated
- A solid foundation for future expansion
